Enable shared editing in Vercel

Set this up directly in your Vercel project. A Codex integration is not required.

  1. Create private storage

    In the project's Storage tab, create a private Blob store and connect it to Production. Vercel provides the storage connection settings automatically.

  2. Set the two passwords

    In Settings > Environment Variables, add CMS_EDITOR_PASSWORD for the team and CMS_OWNER_PASSWORD for the owner. Use different passwords with at least 16 characters each. Select Production.

  3. Redeploy and return here

    In Deployments, redeploy the latest production deployment. Then click Check activation below.
